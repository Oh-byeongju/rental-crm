## 확정된 주요 결정사항

### 스택
- 백오피스: Spring Boot + Thymeleaf + AdminLTE (Bootstrap 기반 어드민 템플릿)
- 고객 포털: React 18 + Zustand + Axios + AntD/MUI + Toss Payments
- 백엔드: Spring Boot 3.x + JPA (Hibernate) + Spring Kafka + Spring Data Redis
- DB: Oracle 21c (Docker — gvenzl/oracle-free)
- 인프라: Docker Compose — 레이어 분리 (infra / backend / frontend)
- CI/CD: GitHub Actions

### UI 그리드
- 백오피스 그리드: AdminLTE + DataTables.js (서버사이드 페이징)
- "그리드 집중" 방향 — 목록 화면 위주로 빡세게 구현할 것

### 개발 방식
- 바이브 코딩 (AI 활용 개발) 비중 높음
- 기획~배포 전 단계 직접 수행
