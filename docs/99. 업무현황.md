## 확정된 주요 결정사항 (ADR 10개)

### 스택 (ADR-006/007)
- **백오피스**: Spring Boot 3.5 + Thymeleaf + **Tabler** (Bootstrap 5) + **AG Grid Community**
- **고객 포털 (Phase 2)**: React 18 + Tailwind + **shadcn/ui** + **TanStack Table**
- **백엔드**: Spring Boot 3.5 + JPA + Spring Kafka + Spring Data Redis + JJWT
- **DB**: Oracle 21c (Docker)
- **인프라**: Docker Compose — infra / backend 레이어 분리

### 권한 모델 (ADR-008/009/010)
- **AUTH 키 행 단위** (`CM_AUTH` 마스터 57개) — 메뉴 R/W/D 폐기 (ADR-008)
- **사용자 직접 권한 매핑** (`CM_USER_AUTH` GRANT/REVOKE) — 역할 폭증 회피 (ADR-009)
- **Redis 권한 캐시** (`permissions:user:{userId}`, TTL 30분) + invalidation 트리거 (ADR-010)
- **JWT 도입은 별도 사이클** — 현재 `X-User-Id` 헤더 임시 시뮬레이션 (ADR-010 §2-8)

### 개발 방식
- 바이브 코딩 (AI 활용 개발) 비중 높음
- 기획~배포 전 단계 직접 수행
- **main 단일 브랜치 + worktree 작업** → rebase 후 main 직접 push (PR 미사용)

## 메모

- 로그인 평문 (학습용): **admin@rental.com / Admin1234!** (AdminSeeder 가 자동 INSERT)
- `X-User-Id: {userId}` 헤더로 임시 사용자 시뮬레이션 (curl/Postman 테스트용). JWT 도입 시 제거.
- AdminSeeder 가 admin 의 `CUSTOMER_EXPORT` GRANT 1개 자동 시드 (UI 검증용 — SUPER_ADMIN 이라 권한 판정엔 영향 없음)
- 사이드바: 권한 없으면 메뉴 안 보임. 비인증 (X-User-Id 없음) → 전체 메뉴 (학습 편의)
- 19 테이블 구성: CM 9 (CODE_GROUP/CODE/ROLE/MENU/AUTH/ROLE_AUTH/USER/USER_AUTH/NOTIFICATION) + CT 6 (CUSTOMER/EQUIPMENT/PRODUCT/CONTRACT/ENGINEER/VISIT) + BL 4 (BILLING/PAYMENT/OVERDUE/BATCH_LOG)
- 배포는 Oracle Cloud Free Tier 검토 중 (Railway/Render 는 Oracle 미지원)
