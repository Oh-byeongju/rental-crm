## 확정된 주요 결정사항 (ADR 14개)

### 스택 (ADR-006/007)
- **백오피스**: Spring Boot 3.5 + Thymeleaf + **Tabler** (Bootstrap 5) + **AG Grid Community**
- **고객 포털 (Phase 2)**: React 18 + Tailwind + **shadcn/ui** + **TanStack Table**
- **백엔드**: Spring Boot 3.5 + JPA + Spring Kafka + Spring Data Redis + JJWT
- **DB**: Oracle 21c (Docker)
- **인프라**: Docker Compose — infra / backoffice 레이어 분리

### 권한 모델 (ADR-008/009/010)
- **AUTH 키 행 단위** (`CM_AUTH` 마스터 59개) — 메뉴 R/W/D 폐기 (ADR-008)
- **사용자 직접 권한 매핑** (`CM_USER_AUTH` GRANT/REVOKE) — 역할 폭증 회피 (ADR-009)
- **Redis 권한 캐시** (`permissions:user:{userId}`, TTL 30분) + invalidation 트리거 (ADR-010)
- **JWT 도입은 별도 사이클** — 현재 `X-User-Id` 헤더 임시 시뮬레이션 (ADR-010 §2-8)

### 도메인 패턴 (ADR-011/012/013, 2026-05-12 2회차)
- **자동 채번** — 임시값 INSERT + assign UPDATE 패턴 (ADR-011) — 계약 `CT-YYYYMMDD-NNNNN` / 청구 `BL-YYYYMM-NNNNNN` / 수납 `PAY-YYYYMM-NNNNNN`
- **상태 전이 allow-list** — Entity 안 `Set<String> XXXABLE_STATUS` 상수로 명시 (ADR-012) — 계약 / 방문 / 청구 / 수납 모두 적용
- **코드 구조 강화 (S1+S2)** — ref-project `sy_code_dtl` 차용: `CM_CODE_GROUP.SYSTEM_YN` + `CM_CODE.DESCRIPTION` + `PROP_VAL1~3` (ADR-013) — 시스템 그룹 변경 차단

### 아키텍처 분리 (ADR-014, 2026-05-13 4회차)
- **배치 모듈 분리** — `rental-batch` 별도 Spring Boot 앱. `backend/` → `backoffice/` 개명. `domain/` 라이브러리 모듈 추출. Gradle 멀티 모듈.
- **통신**: 1차 REST 비동기 fire-and-forget → Ch.3 학습 후 일부 Kafka 토픽.
- **포트**: backoffice 9091 / batch 9093 (9092 = Kafka broker 충돌).
- **패키지**: `com.rental.{backoffice,batch,domain}` (group 분리).
- **시나리오**: 청구·연체·수납·미납통계·에너지동기·회계갱신·통계집계 등 도메인별 배치 메뉴화 (가상 도메인명).
- 2026-05-12 LATER §"배치 모듈 분리" 결정 폐기 (학습 단계와 최종 구조 동일하게).
