# 화면 설계서

> 본 문서는 화면 레이아웃·컴포넌트 매핑·도메인별 검색/그리드 컬럼/팝업 명세.
> UI 결정: [ADR-007](decisions/ADR-007-ui-template-and-grid-library.md)
> - 백오피스: Tabler(Bootstrap 5) + AG Grid Community
> - 고객 포털: shadcn/ui(Tailwind) + TanStack Table + Stitch 시안

---

## 0. 메뉴 트리

```
백오피스
├── 대시보드
├── 공통관리
│   ├── 공통코드 관리
│   ├── 권한 관리
│   ├── 메뉴 관리
│   └── 관리자 계정
├── 고객 관리
├── 장비 / 상품 관리
│   ├── 장비 관리
│   └── 상품 관리
├── 계약 관리
├── 기사 관리
│   ├── 기사 목록
│   └── 방문 이력
├── 청구 관리
│   ├── 청구 목록
│   └── 월 청구 생성 (배치)
├── 수납 관리
├── 연체 관리
├── 알림 내역
└── 통계 / 리포트
    ├── 청구 현황 엑셀
    ├── 미납 현황 엑셀
    └── 월별 수납 통계

├── 로그인 / 회원가입
├── 청구 조회 (목록)

├── 납부 내역
└── 계약 현황
```

## 1. 백오피스 공통 레이아웃

### 1-1. Tabler 베이스 — `dashboard.html` 데모 매핑

**참조**: https://preview.tabler.io/layout-vertical.html

```
┌─────────────────────────────────────────────────────────┐
│ ① 헤더 (Tabler `navbar`)                                │
│   로고 │ 검색 │ 알림(🔔) │ 사용자(이메일 ▼)              │
├──────────┬──────────────────────────────────────────────┤
│ ② 사이드│ ③ 본문 (Tabler `page-body`)                  │
│   바     │   ┌────────────────────────────────────────┐ │
│ (네비)   │   │ 페이지 제목 + breadcrumb               │ │
│          │   │ 우측: 액션 버튼 (조회/저장/삭제/초기화)│ │
│  메뉴 트리│   ├────────────────────────────────────────┤ │
│  (CM_MENU│   │ 검색 카드 (Tabler `card`)              │ │
│   기반)  │   │   [검색조건 form]      [조회] [초기화] │ │
│          │   ├────────────────────────────────────────┤ │
│          │   │ 그리드 카드                            │ │
│          │   │   AG Grid (체크박스/페이징/정렬)       │ │
│          │   │   행 더블클릭 → 상세 모달              │ │
│          │   └────────────────────────────────────────┘ │
└──────────┴──────────────────────────────────────────────┘
```

### 1-2. 공통 컴포넌트 매핑

| 영역 | Tabler 컴포넌트 | 비고 |
|---|---|---|
| 페이지 헤더 | `page-header` | 제목 + breadcrumb + 우측 액션 버튼 |
| 검색 폼 | `card` + `form-control` | 카드 안에 form. 우측 끝 조회/초기화 버튼 |
| 그리드 | **AG Grid Community** | `<div id="grid" class="ag-theme-quartz"></div>` |
| 모달(팝업) | `modal` (Bootstrap 5) | 등록/수정/상세 공용 |
| 토스트 알림 | `toast` | 저장/삭제 결과 |
| 로딩 | `spinner-border` | AG Grid 로딩 오버레이 사용 |
| 사이드바 | `navbar-vertical` | 메뉴 트리 (다단계 collapse) |

### 1-3. AG Grid 표준 옵션 (모든 그리드 공통)

```javascript
const gridOptions = {
  rowSelection: 'multiple',
  pagination: true,
  paginationPageSize: 20,
  paginationPageSizeSelector: [20, 50, 100],
  defaultColDef: {
    sortable: true,
    filter: true,
    resizable: true,
    minWidth: 100,
  },
  rowHeight: 36,
  headerHeight: 40,
  animateRows: true,
  suppressColumnVirtualisation: false,
  // 행 더블클릭 → 상세 모달
  onRowDoubleClicked: (e) => openDetailModal(e.data),
};
```

### 1-4. 표준 CRUD 화면 패턴 (도메인 공용)

```
[ 페이지 헤더 ]
├─ 제목: "{도메인명} 관리"
└─ 우측 액션: [+ 등록] [엑셀 다운로드]

[ 검색 카드 ]
├─ 입력 필드 4-6개 (도메인별 명세)
├─ 우측: [조회] [초기화]

[ 그리드 카드 ]
├─ AG Grid (체크박스 컬럼 + 도메인 컬럼들)
├─ 행 더블클릭 → 상세/수정 모달

[ 모달 (등록/수정/상세) ]
├─ 모달 제목: "{도메인} 등록" / "{도메인} 수정" / "{도메인} 상세"
├─ Form 입력 필드
├─ 하단: [저장] [삭제(수정 모드만)] [닫기]
```

## 2. 백오피스 도메인별 화면 명세

> 모든 도메인은 §1-4 표준 CRUD 패턴 따름. 도메인별 차이 부분만 명시.

### 2-1. 로그인 (`/login`)

| 항목 | 명세 |
|---|---|
| 참조 Tabler 데모 | `sign-in.html` |
| 필드 | 이메일 / 비밀번호 / "로그인 유지" 체크박스 |
| 액션 | [로그인] / "비밀번호 찾기" 링크 |
| 에러 | 카드 상단 alert (5회 실패 시 "30분 잠금" 메시지) |

### 2-2. 대시보드 (`/`)

| 항목 | 명세 |
|---|---|
| 참조 Tabler 데모 | `index.html` (dashboard) |
| 위젯 | 4개 카드 — 전체 계약수 / 이번달 청구건수 / 미납 수 / 이번달 수납액 |
| 차트 | Chart.js — 월별 수납 추이 (라인) + 청구 상태별 분포 (도넛) |
| 최근 알림 | 우측 카드 — 최근 10건 |
| 데이터 출처 | `GET /api/dashboard/summary` (Redis 캐시 5분 TTL) |

### 2-3. 공통코드 관리 (`/sys/codes`)

| 항목 | 명세 |
|---|---|
| 검색 조건 | 그룹코드 (select) / 코드값 (text) / 사용여부 (radio) |
| 그리드 컬럼 | ☑ / 그룹코드 / 코드값 / 코드명 / 정렬순서 / 사용여부 / 등록일시 |
| 모달 필드 | 그룹코드(수정 시 readonly) / 코드값 / 코드명 / 정렬순서 / 사용여부 / 비고 |
| 특수 | 코드 그룹 선택 시 그리드 자동 필터링 |

### 2-4. 권한 관리 (`/sys/roles`)

| 항목 | 명세 |
|---|---|
| 좌측 패널 | 역할 목록 (역할 선택 → 우측에 메뉴 권한 표시) |
| 우측 패널 | 메뉴 트리 + 권한 체크박스 (READ/WRITE/DELETE 컬럼) |
| 액션 | [저장] (역할별 메뉴 권한 일괄 갱신) |
| 특수 | SUPER_ADMIN 역할은 모든 권한 disabled (수정 불가 표시) |

### 2-5. 메뉴 관리 (`/sys/menus`)

| 항목 | 명세 |
|---|---|
| 좌측 | 메뉴 트리 (드래그앤드롭 정렬) |
| 우측 | 선택된 메뉴 편집 form (메뉴명 / URL / ICON_CLASS / 부모메뉴 / 정렬순서 / 타입 GROUP/LEAF) |
| 액션 | [추가] [수정] [삭제] |

### 2-6. 관리자 계정 (`/sys/users`)

| 항목 | 명세 |
|---|---|
| 검색 조건 | 이메일 / 이름 / 역할 / 사용여부 |
| 그리드 컬럼 | ☑ / 이메일 / 이름 / 연락처 / 역할명 / 사용여부 / 마지막 로그인 / 잠금여부 |
| 모달 필드 | 이메일 / 비밀번호(수정 시 별도 버튼) / 이름 / 연락처 / 역할(select) / 사용여부 |
| 특수 액션 | 행 우측 버튼: [잠금해제] (LOCKED_AT not null 시만 표시) |

### 2-7. 고객 관리 (`/customers`)

| 항목 | 명세 |
|---|---|
| 검색 조건 | 고객명 / 연락처 / 이메일 / 계약상태 (계약 1건 이상 ACTIVE/SUSPENDED/TERMINATED) |
| 그리드 컬럼 | ☑ / 고객번호 / 고객명 / 이메일 / 연락처 / 활성계약수 / 등록일 / 사용여부 |
| 모달 | 4 탭 — **기본정보 / 계약이력 / 청구이력 / 납부이력** |
| 기본정보 탭 | 고객번호(readonly) / 고객명 / 이메일 / 연락처 / 생년월일 / 우편번호+주소 / 약관동의 |
| 계약이력 탭 | 내부 그리드 — 계약번호 / 상품명 / 기간 / 상태 |
| 청구이력 탭 | 내부 그리드 — 최근 12건 |
| 특수 | 신규 등록 모달에 비밀번호 입력 (BCrypt). 약관 동의 미체크 시 저장 차단 |

### 2-8. 장비 관리 (`/equipments`)

| 항목 | 명세 |
|---|---|
| 검색 조건 | 장비유형 / 모델명 / 제조사 / 사용여부 |
| 그리드 컬럼 | ☑ / 장비코드 / 장비유형 / 모델명 / 제조사 / 출시일 / 사용여부 |
| 모달 필드 | 장비코드(자동생성) / 장비유형(select) / 모델명 / 제조사 / 출시일 / 이미지URL / 설명 |

### 2-9. 상품 관리 (`/products`)

| 항목 | 명세 |
|---|---|
| 검색 조건 | 장비 / 상품명 / 사용여부 |
| 그리드 컬럼 | ☑ / 상품코드 / 상품명 / 장비명 / 월렌탈료 / 계약기간(개월) / 보증금 / 설치비 / 사용여부 |
| 모달 필드 | 상품코드 / 장비(select 팝업) / 상품명 / 월렌탈료 / 계약기간 / 보증금 / 설치비 / 설명 |

### 2-10. 계약 관리 (`/contracts`)

| 항목 | 명세 |
|---|---|
| 검색 조건 | 고객명 / 상품명 / 계약상태 / 계약기간 (date range) |
| 그리드 컬럼 | ☑ / 계약번호 / 고객명 / 상품명 / 월렌탈료 / 시작일 / 종료일 / 상태 / 설치주소 |
| 모달 (등록) | 고객(select 팝업) → 상품(select 팝업, 선택 시 월렌탈료 자동) → 기간 / 설치주소 |
| 모달 (상세) | 4 탭 — **기본 / 일시정지이력 / 방문이력 / 청구이력** |
| 행 액션 | [일시정지] [재개] [해지] (상태에 따라 disabled) |
| 해지 모달 | 해지사유(필수) + 미납 청구 존재 시 경고 alert |

### 2-11. 기사 관리 (`/engineers`)

| 항목 | 명세 |
|---|---|

| 모달 필드 | 기사코드(자동) / 기사명 / 유형(radio) / 연락처 / 이메일 / 담당지역 |

### 2-12. 방문 이력 (`/visits`)

| 그리드 컬럼 | ☑ / 계약번호 / 고객명 / 기사명 / 방문유형 / 예정일 / 완료일 / 상태 |

### 2-13. 청구 목록 (`/billings`)

|---|---|

| 행 액션 | [수납등록] (UNPAID/OVERDUE 만) |

### 2-14. 월 청구 생성 배치 (`/billings/batch`)

| 항목 | 명세 |
|---|---|
| 입력 | 청구월 (월 select, default 다음 달) |

## 3. 고객 포털 화면 명세 (Stitch 시안)

> ⏸ **Phase 2 — 백오피스 완성 후 진행**.
> 백오피스로 CRUD 풀 사이클 + 학습 시나리오 3개(bulk INSERT / 쿼리튜닝 / Kafka) 모두 검증 가능.
> 고객 포털은 백오피스가 안정된 후 React + Tailwind + shadcn/ui + TanStack Table 로 구축.
>
> 5개 화면 모두 Stitch 로 디자인 시안 작성 → 캡처/PNG 를 본 산출물에 첨부 (Phase 2 진입 시).
