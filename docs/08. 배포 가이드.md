# 배포 가이드

---

## 1. 프로젝트 디렉토리 구조

```
rental-crm/
├── infra/
│   └── docker-compose.yml     ← Oracle / Kafka / Zookeeper / Redis
├── backoffice/
│   ├── Dockerfile
│   └── docker-compose.yml     ← Spring Boot (Thymeleaf 백오피스 + API)
└── frontend/
    ├── Dockerfile
    └── docker-compose.yml     ← React 고객 포털
```

각 레이어를 독립적으로 관리. 인프라 / 앱 / 프론트 책임 분리.

---

## 2. infra/docker-compose.yml

```yaml
version: '3.8'

services:
  oracle:
    image: gvenzl/oracle-free:latest
    container_name: rental-oracle
    environment:
      ORACLE_PASSWORD: oracle
    ports:
      - "1521:1521"
    volumes:
      - oracle-data:/opt/oracle/oradata

  zookeeper:
    image: confluentinc/cp-zookeeper:latest
    container_name: rental-zookeeper
    environment:
      ZOOKEEPER_CLIENT_PORT: 2181

  kafka:
    image: confluentinc/cp-kafka:latest
    container_name: rental-kafka
    depends_on:
      - zookeeper
    ports:
      - "9092:9092"
    environment:
      KAFKA_BROKER_ID: 1
      KAFKA_ZOOKEEPER_CONNECT: zookeeper:2181
      KAFKA_ADVERTISED_LISTENERS: PLAINTEXT://localhost:9092
      KAFKA_OFFSETS_TOPIC_REPLICATION_FACTOR: 1

  redis:
    image: redis:7-alpine
    container_name: rental-redis
    ports:
      - "6379:6379"

volumes:
  oracle-data:
```

## 3. backoffice/docker-compose.yml

```yaml
version: '3.8'

services:
  app:
    build: .
    container_name: rental-app
    ports:
      - "8080:8080"
    environment:
      SPRING_DATASOURCE_URL: jdbc:oracle:thin:@localhost:1521/FREEPDB1
      SPRING_DATASOURCE_PASSWORD: oracle
      SPRING_KAFKA_BOOTSTRAP_SERVERS: localhost:9092
      SPRING_REDIS_HOST: localhost
```

---

## 4. frontend/docker-compose.yml

```yaml
version: '3.8'

services:
  frontend:
    build: .
    container_name: rental-frontend
    ports:
      - "3000:80"
    environment:
      REACT_APP_API_URL: http://localhost:8080
```

---

## 5. 로컬 개발 실행 순서

```bash
# 1. 인프라 먼저 띄우기
cd infra
docker-compose up -d

# 2. 백엔드 IDE에서 실행 (개발 중)
# 또는 컨테이너로 실행
cd backoffice
docker-compose up -d

# 3. 프론트엔드 개발 서버 실행
cd frontend
npm run dev

# 4. 접속
# 백오피스:   http://localhost:8080
# 고객 포털:  http://localhost:3000
```
