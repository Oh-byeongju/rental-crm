# 회고 (Retro)

> 작업 중 발견된 패턴·실수·결정 사항을 기록. 다음 사이클의 학습 자료.

---

## 사용 방법

- 파일명: `YYMMDD_주제.md` (예: `260512_권한모델_AUTH키단위_전환.md`)
- 회고 단위:
  - 한 사이클 끝 (작업 묶음 마무리 시)
  - 큰 결정 후 (ADR 작성 + 회고 동시)
  - 실수 인지 시 (재발 방지)

## 분류

회고 본문에 다음 중 하나 이상의 태그:

- `pattern` — 잘 작동한 패턴 (다음에 재사용)
- `mistake` — 실수 + 재발 방지 방법
- `tradeoff` — 트레이드오프 결정 + 사후 평가
- `tooling` — 도구·자동화 평가

## ADR 과의 차이

| | ADR | Retro |
|---|---|---|
| 시점 | 결정 직전 (의사결정) | 결정 후 (사후 평가) |
| 내용 | 대안 비교 + 채택 근거 | 작업해보니 어땠는지 |
| 가변성 | 보강·후속 가능, 본문은 고정 | 자유 형식 |
| 예 | ADR-008 (메뉴 RWD → AUTH 키) | 260512_AUTH키_전환_2주차_평가.md |
