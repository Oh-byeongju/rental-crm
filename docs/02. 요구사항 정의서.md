# 요구사항 정의서

---

## 1. 관리자 (백오피스)

### 1-1. 공통 관리
- 공통코드 그룹 / 코드 등록·수정·삭제 (장비유형, 계약상태, 청구상태 등)
- 관리자 계정 등록·수정·비활성화
- 권한 관리 (역할별 메뉴 접근 제어)
- 메뉴 관리

### 1-2. 회원(고객) 관리
- 고객 목록 조회 (검색: 이름 / 연락처 / 계약상태)
- 고객 등록·수정
- 고객 상세 조회 (계약 이력, 청구 이력 포함)

### 1-3. 장비 / 상품 관리
- 장비 목록 조회
- 장비 등록·수정 (장비유형, 모델명, 제조사)
- 상품 목록 조회
- 상품 등록·수정 (장비 연결, 월 렌탈료, 계약 기간)

### 1-4. 계약 관리
- 계약 목록 조회 (검색: 고객명 / 상품 / 계약상태)
- 계약 등록 (고객 + 상품 + 기간 + 월 렌탈료)
- 계약 수정
- 계약 해지

### 1-5. 기사 관리
- 기사 목록 조회
- 기사 등록·수정
- 방문 배정 (계약 체결 후 설치 방문 배정)
- 방문 이력 조회

### 1-6. 청구 관리
- 청구 목록 조회 (검색: 고객명 / 청구월 / 청구상태)
- 월 청구 일괄 생성 배치 실행 (매월 1일 전체 계약 건 대상)
- 청구 상세 조회

### 1-7. 수납 관리
- 수납 처리 (청구 건별 수납)
- 수납 이력 조회

### 1-8. 연체 관리
- 연체 현황 조회
- 연체 상태 처리 (Kafka 이벤트 연동)

### 1-9. 대시보드
- 전체 계약 수 / 이번 달 청구 수 / 미납 수 / 월 수납액 집계 표시
- 집계 쿼리 성능 측정 대상

### 1-10. 알림 내역
- Kafka 이벤트 consume 결과를 알림 테이블에 저장
- 알림 목록 조회 (청구 생성 / 수납 완료 / 연체 발생 등)

### 1-11. 통계 / 리포트
- 청구 현황 엑셀 다운로드
- 미납 현황 엑셀 다운로드
- 월별 수납 통계

---

## 2. 사용자 (SPA 프론트)

### 2-1. 인증
- 회원가입 (이메일 + 비밀번호)
- 로그인 / 로그아웃 (JWT)
- SSO는 추후 옵션

### 2-2. 청구 조회
- 내 청구 목록 조회
- 청구 상세 조회

### 2-3. 납부 내역
- 납부 이력 확인

### 2-4. 계약 현황
- 내 계약 목록 조회

### 2-5. 카드 납부
- 청구 건 선택 후 카드 결제 (PG 연동 — Toss Payments)
- 결제 완료 시 수납 처리 + Kafka 이벤트 발행

---

## 3. 비기능 요구사항

### 성능
- 월 청구 일괄 생성: 5만 건 기준 처리 시간 측정 및 목표 수치 설정
- 대량 조회 (수십만 건) 응답 시간 목표 설정
- 엑셀 다운로드: 스트리밍 처리 (OOM 방지)

### 운영
- 배치 실행 이력 기록 (멱등성 보장 — 재실행 시 중복 청구 방지)
- Docker 기반 로컬 실행 환경 구성
